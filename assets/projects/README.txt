PILTIDE VAHETAMINE — ILMA KOODITA

1. Ava see kaust Finderis.
2. Vali pilt, mida tahad muuta, näiteks project-01.png.
3. Nimeta oma uus pilt täpselt samaks: project-01.png.
4. Lohista uus fail sellesse kausta ja vali “Replace”.
5. Ava portfolio.html uuesti või tee brauseris tugev refresh: Cmd + Shift + R.

See on kõik. Portfolio kasutab iga pildi jaoks sama failinime, mistõttu HTML-i ega JavaScripti muuta ei ole vaja.

TÄHTIS
- Hoia uued pildid PNG formaadis, kui asendad olemasolevaid demo pilte.
- Parima tulemuse jaoks kasuta vähemalt 1600 px laiust pilti.
- project-02.png, project-05.png, project-06.png, project-09.png ja project-10.png sobivad eriti hästi vertikaalsete piltide jaoks.
- Kui soovid oma pilti kasutada uue projektina, mitte olemasoleva asemel, tuleb lisada ainult üks uus rida failis data/projects.js. Juhis on projekti README.md-s.
